# Sketch Together / Tutorial 15
Run npm ci then npm start from this directory. Open http://localhost:3000 in two tabs and draw. npm test verifies shared drawing and clear events.
Deploy the root render.yaml on Render. Add the real service URL and a screenshot of two connected tabs to the draft PDF before submission.
This app uses native Canvas with Node.js / Socket.IO; the assignment tutorial demonstrates p5.js. Review with your instructor if following p5.js specifically is required.
