01 / Customized Background

A Reactive Canvas Behind the Site

The canvas fills the browser window, stays behind the HTML, and does not block any links. The grid bends around an eased pointer while animated waves move through the background.

Live input

Move, tap, or click anywhere.

Pointer movement changes the center of the field. Clicking shifts the colors and releases a pulse, while touch input provides the same interaction on a phone or tablet.

How the Sketch Works

The sketch follows the Tutorial 12 structure with a separate HTML, CSS, and JavaScript file, plus the p5.js library loaded before the custom sketch.

01

Canvas Parent

canvas.parent("canvas-container") places the p5 canvas inside a specific HTML element.

02

CSS Background

Fixed positioning, layering, and pointer-events: none keep the interactive HTML usable above the canvas.

03

Loops + Waves

Nested for loops repeat the grid while sin() creates the moving wave lines and shifting signal pattern.

04

Eased Input

The current position moves partway toward the pointer every frame, creating a smoother chase effect on mouse and touch devices.
