# Tutorial 14 - AI Agent Website

The website used for this tutorial is **New World, Nexus**, located at:

`../../projects/03-net-art/`

It is an original interactive net artwork with a futuristic visual system,
responsive images, CSS animation, pointer-responsive effects, a drawable G-code
field, draggable interface fragments, and session counters.
