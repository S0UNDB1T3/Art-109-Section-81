NEW WORLD, NEXUS
Project 3 - Net Art
Richard Allen Rojas-Rangel

FILES
- index.html: semantic structure and artwork content
- style.css: responsive layout, visual system, transitions, and animation
- script.js: G-code canvas, draggable fragments, messages, counters, and motion
- assets/: original responsive visual assets

HOW TO VIEW
Open index.html in a modern browser. No installation or internet connection is
required. The experience works best with a mouse or touchscreen, but all major
controls support keyboard navigation.

INTERACTIONS
- Move the pointer to shift the visual field.
- Hover over the archive image to change its integrity reading.
- Draw inside the G-code field or use Generate Path.
- Drag interface fragments or move them with the arrow keys.
- Click the transmission panel to decode conceptual messages.
- Erase the session to return the work to its original state.

PRIVACY
The work does not collect, upload, or permanently store visitor information.
All counters and changes exist only in the current browser session.

AI USE DISCLOSURE
OpenAI Codex assisted with code development, debugging, browser testing, and
submission packaging. Richard Allen Rojas-Rangel directed the concept, visual
style, interactions, revisions, and final decisions. This disclosure is included
to follow the ART 109 Tutorial 14 and CSU responsible AI-use requirements.
